# Task Status

The task files are the source of truth. The board in `docs/tasks/README.md` is a view of
them, generated by `docs/tasks/tasks.py`, never written by hand or from memory.

## Non-goals

- Do not edit any task file: not the status, not the checkboxes, not the logs. A status
  that looks wrong is reported, and the person who owns that transition fixes it.
- Do not report progress that is not visible in a task file.
- Do not invent due dates, assignees or percentages.

## Workflow

1. If `docs/tasks/tasks.py` is missing, stop and load `task-brief` to set the folder up.
2. Run `python3 docs/tasks/tasks.py lint` and keep the output.
3. Run `python3 docs/tasks/tasks.py board`. It rewrites only the section between the board
   markers and prints the counts and one line per task with its flags.
4. If `NOTION_DATABASE_ID` is set in the environment or `.env`, run
   `python3 docs/tasks/notion_sync.py` to mirror the tasks to Notion. Report its summary
   line; a Notion error is reported, not retried by hand, and does not stop the digest.
   When it prints `pull` lines, questions added or ticked in Notion were written into
   task files: list them in the digest and tell the user to commit them.
5. Read the files behind every flagged or open task, plus any `PLAN-*.md`, to work out:
   - decisions the user owns (open questions and plan decisions naming them);
   - mismatches to report: a task that is In progress with every criterion ticked and no
     hand-in, Done without an accepted review (`UNVERIFIED`), Blocked with no open
     question, dependencies that point the wrong way;
   - the next action per open task, named by person: start, unblock, hand in, review.
6. Reply with a digest of at most fifteen lines: counts per status, the decisions needed
   from the user, the next action per open task, and lint errors if any.

## Rules

- A contradiction between the board and a task file is resolved in favour of the file by
  regenerating the board, and reported.
- A task with no dated activity and no hand-in is `Todo`, however long ago it was assigned.
- English, ASCII only, no emoji in files; the digest follows the user's language.

## Output contract

- The board between `<!-- status-board:start -->` and `<!-- status-board:end -->`,
  regenerated by `tasks.py board`, and the Notion mirror when it is configured.
- A chat digest: counts, decisions needed, next action per open task.
